# RAM 与 SimplePE：从原始算例得到的接入经验

## 实际入口与能力边界

- RAM：本机 `bin/ram.exe`，读取工作目录固定名 `ram.in`，输出 `tl.grid` 和 `tl.line`。`tests/Dickins` 是海山，`tests/wedge` 是坡底；不是 ENV/FLP 入口。
- `ram.m` 运行 exe 后调用 `RAMtoSHD`；后者写死外部F盘路径，而且没有逐列跳过Fortran记录标记，深度维度还按含0端点推算。不应原样用于本次二进制。
- 本机已有正确跳过记录标记的 `ReadWrite/read_ram_tlgrid.m`，也可由 `read_shd('tl.grid')` 分派；`Slicer/run_ram.m` 使用这一读取器。应先查现有辅助函数，而不是只看根目录wrapper。
- SimplePE 是独立 MATLAB 抛物方程实现，本机 `simplePE.m` 自述使用较简单的近似，不能把它与 RAM 当作同一求解器。实际由 BELLHOP 格式 ENV 与 BTY 等读取环境，输出 `.shd.mat`。

## ram.in 结构与单位

| 段 | 意义与容易出错处 |
|---|---|
| 标题 | 第一行描述算例 |
| freq, zs, zr | Hz、源深m、固定接收曲线深度m |
| rmax, dr, ndr | 最大距离m、内部距离步长m、距离输出抽样因子；与AT常用km距离区分 |
| zmax, dz, ndz, zmplt | 计算深度m、内部深度步长m、深度输出因子、绘图深度m；计算域要包含海底吸收区域 |
| c0, np, ns, rs | 参考声速、Padé项数、稳定控制及其距离；np是整数控制量，并非NumPy |
| rb, zb | 沿程距离m和海底深度m；负值对结束此段 |
| z,cw / z,cb / z,rhob / z,attn | 水体声速、沉积物声速、密度和衰减剖面，分别以负值对结束；单位和深度参考按RAM版本/手册核对 |
| rp 与后续剖面 | 在后续传播距离更新环境；不能把只有表层数据的剖面外推成任意多层海底 |

先复制基准、核对采样和单位，再修改研究变量。`write_env_RAM.m` 包含自动猜测网格/计算域的逻辑，不能把自动生成当作已收敛。

## 新结果读取与独立检查

读取 `scripts/read_ram_grid.py`：对本机格式检查60字节头、每个距离列前后的记录标记、实际列数、维度和非有限值。保存原始 TL 与坐标，不把它伪装为含相位的复声压。

本次有独立的深度探针：wedge 设置 zr=1 m 后，首行grid与line在全部输出距离上的最大差约4.9e-7 dB。这确认本机exe的物理深度为 `(样本序号*ndz-1)*dz`，而本机MATLAB读取器标注为 `样本序号*ndz*dz`，相差一个内部dz。该结论针对已测二进制；换编译版本须重做探针，不能按文件扩展名自动推广。

源码参考（同时核对了setup、outpt中的索引）：https://oalib-acoustics.org/website_resources/PE/RAM.ORG/ram.f 。本机运行的输入/输出哈希与探针证据见深度审查报告。不能仅凭网上源码认定本机exe版本完全相同。

`tl.grid` 只有幅度形式的传播损失。`10^(-TL/20)` 只恢复模，不能恢复相位；旧转换生成正实数pressure，不适合相位、到达时间或宽带传递函数研究。

## 本次试验带来的限制

- RAM wedge原例、距离步长减半、深度步长减半、Dickins海山均实际执行。执行/格式检查通过不等于网格收敛。
- wedge距离步长减半，输出距离保持一致，湿点且r≥200 m的TL最大差约28.50 dB、P95约2.04 dB；不能把基准声场直接称为稳定。
- dz改变时，即使ndz同步调整，物理输出深度仍可能发生半格偏移；不能直接逐点相减冒充同坐标收敛。
- SimplePE wedgeB已实际执行，源代码存在固定的每波长采样、海底延拓和起始场设置；修改它们须在研究目录复制版本并保存改动，不能无记录地改全局工具箱。

## 推荐运行链

独立任务目录 → 复制ram.in并记录哈希 → MATLAB system显式调用ram.exe并检查退出码 → 检查新tl.grid/tl.line → 严格读取与坐标探针 → 原始数值/图表 → 网格与边界敏感性 → 研究结论。复现MATLAB旧格式时也保留正确的物理深度坐标说明。
