# 验证技巧（跨模型 / 解析对照的可复用规则）

实际执行后核对结果时，先套用下面三条，避免把“跑通”当成“验证通过”。

## 1. 跨模型对齐法则

比较两个模型（或模型与解析解）的 TL 之前，先对齐三件事，否则差异可能来自选项而非求解器：

- **相干性**：KRAKEN `field.flp` 的 OPT 第 4 位，`C`=相干、`I`=非相干、`S`=半相干；SCOOTER/BELLHOP 常见为相干。拿非相干模态叠加去比相干复声场，中位差会虚高到 3–5 dB（Munk 实测）。
- **源归一化**：AT 点源自由场 `TL = 20 log10(R)`（R 单位米）；线源另有归一化，不能混用。
- **频率 / 源深 / 接收深度 / 坐标单位一致**，且用同一套采样网格（必要时插值到共同网格，插值只对平滑 TL 可靠，干涉区慎用）。

## 2. 解析参照验证法

用“已知真值”验接入，比“同环境互证”更有力：

- **自由场点源**：`TL = 20 log10( sqrt(r² + (z - zs)²) )`。
- **Lloyd 镜像（自由表面）**：`p = exp(i k r1)/r1 − exp(i k r2)/r2`，r1、r2 分别为直达、反射斜距。
- **半空间 / 底反射**：用 BOUNCE 反射系数或 Pekeris 解析解做黄金参照。

free、PointLine 两个族用这套已经做到中位差 < 0.001 dB，说明调用链、归一化和读场是对的。

## 3. 深零点掩码统计

报告用中位 / p90 / p99，不用被干涉零点支配的逐点最大差：

- 掩码：`TL < 150 dB` 视为有效（剔除深零点与数值下限，`-20log10(realmin)≈6151 dB` 就是被钳的零点）。
- 无效点（NaN / Inf / 海底以下 / 海面以上）先转 `float`，再用有限掩码比较；JSON `null` 不能直接当数组相减。
- 共同有效掩码的交集一致率 ≠ 全区域覆盖率，两者要分开说明。

## 4. 边界声明

- 解析真值对照是**强验证**；跨模型互证只证明“接入一致 + 彼此吻合”，不是第三方物理精度认证。
- 逐点最大差常落在干涉零点 / 焦散 / 长距离声线附近，不能当整体精度指标。
