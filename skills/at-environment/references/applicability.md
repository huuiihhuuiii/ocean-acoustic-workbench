# 模型适用性矩阵（选型第一道筛选）

来源：课程/教材常用的定性适用性表（用户提供的图），配合 `models.json` 的逐模型条件使用。
**这是"物理适用性 + 计算可行性"的经验评级，不是本平台的硬限制**：本工作台表单目前只支持距离无关（RI）、单剖面、平底；RD 需独立构造 ENV/FLP 并用 AT 原始 FIELD / RAM / BELLHOP 流程。

图例：● 既物理适用又计算可行；◐ 有计算精度或速度上的限制；○ 物理不适用且计算不可行。
低频 < 500 Hz，高频 > 500 Hz；RI = 水平不变（距离无关），RD = 水平变化（距离相关）。

## 对应到本机 AT 程序

| 模型类别 | 本机程序 | 技能 | 备注 |
| --- | --- | --- | --- |
| 波数积分 | `scooter.exe` + `fields`/`fieldsco` | `at-scooter` | 深度离散同时用有限元，所以它同时落在"有限元"一行 |
| 简正波 | `kraken.exe` / `krakenc.exe` + `field.exe` | `at-kraken` / `at-krakenc` | KRAKEL（弹性模态）缺程序，已从清单移除 |
| 射线 | `bellhop.exe` / `bellhop3d.exe` | `at-bellhop` / `at-bellhop3d` | 声线/波束近似，高频更可靠 |
| 抛物方程 | `ram.exe` / SimplePE 脚本 / `sparc.exe` | `at-ram` / `at-simplepe` / `at-sparc` | RAM 是距离相关前向 PE；SPARC 是时域 PE |
| 有限元 | SCOOTER 的深度有限元；KRAKEL（已移除） | `at-scooter` | AT 没有独立的"有限元"可执行程序 |

## 读法

1. 先按 **水深（浅海/深海）× 频段（<500 / >500 Hz）× RI/RD** 定位格子，再选**模型类别**，最后落到具体程序。
2. ● 不等于"用默认参数就能算对"：仍须检查采样、波束、步长、模态数、谱积分上限等收敛。
3. ○ 是"物理不适用或算不动"，不要硬用；换类别，或查更细的文献与验证。
4. 与本平台表单的差别：表单只给 RI、单剖面、平底；表中 RD 的 ○/◐ 在本平台意味着"需独立构造 ENV/FLP"，不是"表单里能选"。
5. 冲突时以专项 workflow 的数值检查为准：`at-bellhop`（高频射线）、`at-kraken`（低频模态）、`at-scooter`（谱积分/近场）、`at-ram`（沿程变化）各自的条件更细。

## 常见误读

- "射线"在浅海低频是 ○，不代表 BELLHOP 在浅海完全不能用，而是低频下声线/波束近似与波长尺度不匹配，结果不可信；平台对 BELLHOP 的规则是"结合波长、环境尺度、边界与数值稳定性判断"，不是按频率一刀切。
- "简正波"深海高频 RD 是 ○，不代表 KRAKEN 不能算深海；高频下模态数庞大、RD 需逐段配置，代价与精度都受限。
- "有限元"整行 ◐：AT 的有限元是内嵌在 SCOOTER 里的深度离散，不是独立求解器；不要去找一个不存在的 FEM 程序。
