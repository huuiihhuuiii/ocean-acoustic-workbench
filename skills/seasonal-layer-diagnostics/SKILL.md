# 混合层季节诊断

明确经纬范围、季节或月份、空间采样方式及判据。用户只说“某区域”且无上下文范围时，先询问区域；仍可解释方法，但不得将任意一点替代区域。四季用 WOA18 原始季节场13–16；月场1–12与季节场深度范围不同，不能把四季诊断称为全年逐月实测。

用 get_ocean_profile 获取带 requested/selected 和缺测信息的实际数据。研究区域应按实际1°温盐格点去重，说明海岸遮罩、有效点数及面积加权方式；区域内各格点先诊断后汇总，平均剖面诊断不等于混合层深度的空间平均。

读取 scripts/analyze_profiles.py。脚本提供温度和位密度双判据：10 m参考，位温绝对偏差0.2°C、TEOS-10 sigma0 增量0.03 kg/m³，阈值首次穿越线性定位。判据依据 de Boyer Montégut et al. 2004，https://doi.org/10.1029/2004JC002378 。这是从平滑气候平均剖面得到的诊断量，不能当作瞬时观测MLD。

本机 Codex 可在研究目录运行返回的脚本绝对路径；其他执行环境可读取脚本内容后写入研究目录。脚本 --lon/--lat --periods 13,14,15,16 --out-dir 研究目录可直接读取本机数据；--profiles 接受实际剖面JSON数组（支持多点）并计算，不访问外部网络。自定义问题可扩展脚本，保留版本和输入。

无阈值交点时返回 not_crossed 与有效深度界限，不能拿最深层当作MLD；参考深度不足或内部缺测时明确标记。比较阈值0.02/0.03/0.05 kg/m³时属于敏感性实验，不冒充三套真值。

创建并执行研究任务，检查人工剖面的解析交点、季节格点一致性与有效覆盖。产物包括冻结剖面、指标JSON/CSV、MLD季节图和温盐声速图；报告方法、来源和未验证项。若只研究MLD，无需调用声场求解器。
